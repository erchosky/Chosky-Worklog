# Desinstalación

1. En Chosky Worklog, desactiva **Permitir acceso compartido**.
2. Elige **Salir completamente**.
3. Mueve `/Applications/Chosky Worklog.app` a la Papelera.

Para conservar datos, no hagas nada más.

Para borrarlos, mueve manualmente a la Papelera:

```text
~/Library/Application Support/com.chosky.worklog/
~/Library/Logs/com.chosky.worklog/
```

En Ajustes del Sistema puedes retirar Grabación de pantalla y Accesibilidad.
No es necesario modificar Gatekeeper, SIP o TCC mediante Terminal.
