# Permisos

- **Grabación de pantalla:** ScreenCaptureKit. Sin permiso no hay capturas,
  pero sesiones e informes siguen disponibles.
- **Accesibilidad:** el watcher de ventanas. Sin permiso no se promete título
  de ventana.
- **Red local:** solo cuando se activa el panel LAN.
- **Notificaciones:** no necesarias en v0.1.
- **Inicio automático:** no se configura en v0.1.

La pantalla Permisos permite solicitar y volver a comprobar. La aplicación no
reinicia TCC, no modifica SIP y no ejecuta comandos para eludir macOS.
